Teaching-Timetable-Data.xlsx is the live source for the entire platform.

1. Open Teaching-Timetable-Data.xlsx in Microsoft Excel.
2. Edit the yellow cells in Sessions, Professors, Modules or Settings.
3. Keep the existing worksheet names and column headings unchanged.
4. Save the workbook.
5. The live connection detects the saved file and updates the dashboard automatically.
