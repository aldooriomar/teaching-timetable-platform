Workflow

How to update the live dashboard

  1. 1
    Open the workbook

    Go to backend\Teaching-Timetable-Data.xlsx in the extracted application folder.

  2. 2
    Edit the yellow cells

    Use Sessions, Professors, Modules or Settings. Keep the worksheet and column names unchanged.

  3. 3
    Save in Excel

    The application detects the saved file. Leave the browser open or return to it after saving.

  4. 4
    Review the dashboard

    The live connection updates the page after the workbook is saved. You can also select “Reload Excel now”.
